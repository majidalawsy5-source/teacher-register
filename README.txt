سجل المدرس — نسخة PWA تعمل محلياً
================================

1) الاستخدام بدون إنترنت
-------------------------
افتح index.html عبر استضافة ثابتة مجانية (مثل GitHub Pages) أو أي سيرفر ملفات محلي.
بعد فتحه في Safari على iPhone يمكنك إضافة الموقع للشاشة الرئيسية.
Service Worker مفعّل عند فتحه عبر https/http، لذلك يستمر العمل محلياً بعد التحميل الأول.

مهم: فتح index.html مباشرة من تطبيق الملفات بصيغة file:// لا يفعّل Service Worker. مع ذلك تعمل معظم وظائف التطبيق المحلية داخل المتصفح.

2) الحفظ المحلي
---------------
البيانات تحفظ تلقائياً في تخزين المتصفح.
يوجد تبويب النسخ الاحتياطي لتصدير/استيراد JSON.
على الأجهزة التي تدعم showSaveFilePicker يمكن اختيار مكان حفظ ملف JSON مباشرة؛ على iPhone قد يظهر خيار المشاركة/الملفات وفق النظام.

3) استيراد الأسماء
------------------
TXT: كل اسم في سطر.
DOCX: تُقرأ فقرات Word محلياً داخل المتصفح.
DOC القديم: المحاولة مبسطة وقد لا تستخرج كل النصوص من كل ملفات DOC؛ يفضل تحويله إلى TXT أو DOCX إذا لم يُقرأ جيداً.

4) النسخ السحابي الاختياري
--------------------------
النسخة الحالية تدعم Firebase Authentication + Firestore REST.
لا تحتاجه إذا أردت العمل بالكامل بدون إنترنت.

إعداد Firebase (مرة واحدة):
أ) أنشئ مشروعاً في Firebase Console.
ب) أضف Web App للحصول على Web API Key وProject ID.
ج) من Authentication > Sign-in method فعّل Email/Password.
د) أنشئ Firestore Database.
هـ) ضع قواعد Firestore التالية (مثال بسيط):

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/backup/{docId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

و) داخل التطبيق افتح تبويب النسخ السحابي وأدخل API Key وProject ID ثم اسم مستخدم ورمز سري واضغط إنشاء/تفعيل.

ملاحظة: التطبيق يحفظ السجل السحابي بدون الصور الثقيلة. الصور تبقى محلية، لذلك استخدم ملف JSON للحفظ الكامل مع الصور.

5) الطباعة
----------
زر الطباعة العادية يطبع الجدول فقط.
زر الطباعة المخصصة يسمح باختيار أعمدة الدرجات.
سجل الغياب يمكن طباعته للحاضرين فقط أو الغائبين فقط أو كلاهما، ولتواريخ متعددة.

6) أرقام ودرجات
----------------
واجهة الدرجات تستخدم الأرقام العربية (الهندية) عند العرض، وتقبل إدخال 0–100.
المعدلات والسعي والنسب المئوية تقرّب إلى أقرب عدد صحيح كما طلبت.

7) تنبيه مهم بخصوص "الحفظ التلقائي في ملفات الهاتف بعد حذف البرنامج"
--------------------------------------------------------------------
المتصفح لا يملك صلاحية مضمونة للكتابة الصامتة داخل تطبيق "الملفات" ثم استعادة الملف بعد حذف بيانات الموقع أو التطبيق. لذلك يوجد حفظ محلي تلقائي + تصدير JSON، وهو المسار الآمن لاسترجاع نسخة بعد الحذف.
